# Writing platform copy

Write copy a friend would say out loud. Keywords go in as ordinary sentences. Every number comes from a source. The project's own rules beat this skill.

## 0. Discover first

Read the project's instruction files (CLAUDE.md, AGENTS.md, README, docs) and any copy-style doc. Note: language and voice ("I/you", formal or casual), banned phrases, link and affiliate rules, AI-label rules, hashtag rules, the file the copy is saved in, and the keyword tool if one exists. Each item not found goes on the question list. Never fill it from memory or another project.

## 1. Ask which platforms (always the first question)

Use the harness's ask tool, multi-select. It usually allows 4 options per question, so ask twice:

- Video: YouTube Shorts, YouTube long-form, TikTok, Instagram Reels
- More: Facebook Reels, X, Threads, LinkedIn (or "other", free text)

Write only for the platforms chosen. Then ask only what step 0 did not answer: language, main keyword (or "you pick"), link and whether it is affiliate, one version or A/B variants.

## 2. Gather facts

Read the script, voice-over or transcript and the source list. Every price, spec, number and claim needs a source and a check date ("I checked 31 Oct 2026"). No source: leave the claim out. The copy may not promise anything the video does not show.

## 3. Keyword

Pick one main keyword plus 2 to 4 variants written the way people type them (product name, "how to ...", "X vs Y", price class). Use the project's keyword tool if there is one; otherwise reason from search suggestions and say that no volume data was used. Where it goes: title in the first ~40 characters, first sentence of the description or caption as a normal sentence, never pasted on or repeated more than twice.

## 4. Write per platform

Fields, limits and where the link goes: `platforms.md`. For each platform give 2 to 3 title or hook options, pick one, and say why in one line. Different platforms get different text: never paste one caption everywhere.

## 5. Slop check

Run every block through `anti-slop.md`, then read it aloud. If it sounds like a brochure, rewrite it. If it sounds like someone explaining to a friend, it is done.

## 6. Handover

One copy-paste block per platform, with character counts against the limits. Then the settings reminders (AI label, paid-promotion or branded-content toggles, where the link sits) and a short pre-post checklist. Save to the project's copy file. Never publish.

## Red flags: stop and fix

| Thought | Reality |
|---|---|
| "One caption fits all platforms" | Each platform shows a different first line and takes the link differently |
| "A big number sells it" | No source, no number |
| "More hashtags, more reach" | 3 to 5 that match the topic |
| "The title needs a hype word" | Curiosity must be proven by the video, with one trigger only |
| "Add 'like and subscribe'" | Give one specific reason to follow, or nothing |
| "The link goes in the caption" | Check `platforms.md`; most platforms do not make caption links clickable |
